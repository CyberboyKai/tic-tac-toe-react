# 🎮 React Tic-Tac-Toe: Neon Edition

A modern, stylish take on the classic Tic-Tac-Toe game built with **React**. 
Completed as part of the **UVA Forge Launch 2026** assignment.

## ✨ Features
- **Modern Neon UI:** Custom gradients, glassmorphism, and hover animations.
- **Time Travel:** Move history with the ability to jump back to any previous state.
- **Logic Enhancements:** - Automated winner detection.
  - **Draw Detection:** Notifies players when no moves are left.
  - **Clean Code:** Board rendering using loops instead of hardcoding.

## 🛠️ Technologies
- React.js, JavaScript (ES6+), CSS3, Git.
